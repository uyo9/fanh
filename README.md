## FAQs

### Where to get my nhentai API key?

Create one from your [User Settings](https://nhentai.net/user/settings#apikeys).

### Will my nhentai API key be leaked?

No. We do **NOT** collect any user data.

### Why is fanh slow?

It will inevitably slow down when you have more than 375 favourites due to request rate limiting.

### How does fanh work?

See the favourites part in the [official API docs](https://nhentai.net/api/v2/docs#/favorites/get_favorites_api_v2_favorites_get).
